# Forja de Heróis

Fichas e ferramentas de mesa para D&D 5e (regras de 2014) e Ordem Paranormal: criação de personagem passo a passo, fichas, Livro do Jogador, dados, bestiário, tesouro, mapa e geradores.

Esta é a versão para a web aberta. As fichas ficam salvas no navegador de cada pessoa. A mesa online, as fichas guardadas na conta e o cadastro da mesa (conteúdo de outros livros) funcionam só na versão que roda dentro do Claude.

Conteúdo de regras: Documento de Referência do Sistema 5.1 e 5.2 (Creative Commons Atribuição 4.0) e a wiki de Iccarion, com textos escritos para o site.
